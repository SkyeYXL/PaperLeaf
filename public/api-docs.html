PaperLeaf API

将桌面工具、脚本、浏览器扩展或自建服务安全接入 PaperLeaf。所有公开接口位于 /api/v1，面向任意可发送 HTTP 请求的终端。

开始使用

  1. 登录 PaperLeaf，进入设置 → API Token，创建一个用途明确的 Token。
  2. 打开认证与 Token，填写 Token 并执行验证请求。
  3. 按书签、高亮笔记、标签、收藏夹、时间轴或数据模块复制示例。

Token 仅代表一个 PaperLeaf 用户，所有书签和笔记均按所属用户隔离。不要使用网页登录 Cookie 调用外部工具。

请求标准

项目规范
服务地址示例自动使用当前打开的服务地址 ，域名、IP 与端口无需手动修改。
认证Authorization: Bearer <token>
请求格式带请求体的方法使用 UTF-8 JSON 与 Content-Type: application/json。
响应格式普通成功为 { "data": ... }；失败为 { "error": { "code", "message" } }。导出接口直接返回备份 JSON。
路径参数{bookmarkId}、{highlightId}、{tagId}、{collectionId} 必须替换为对应响应中的实际 ID。

功能模块

模块可调用内容
书签列表、保存、详情、更新、重新抓取、删除。
高亮笔记列表、创建、详情、更新、删除。
标签列表、详情、重命名。
收藏夹列表、创建、详情、更新、删除、移出书签。
时间轴按日期读取阅读与笔记活动。
数据导入与导出管理员完整服务数据导出与导入。
