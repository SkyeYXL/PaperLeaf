开发者文档

返回代码

先处理 HTTP 状态码，再根据 error.code 进行提示或重试。

通用响应格式

普通成功响应
{ "data": { "example": "success" } }
错误响应
{ "error": { "code": "INVALID_TOKEN", "message": "Token 无效、已撤销或没有所需权限。" } }

全局返回代码

状态业务代码含义
200—读取、更新、删除、验证或导入成功。
201—书签、高亮笔记或收藏夹创建成功。
400INVALID_HIGHLIGHT高亮内容为空或定位信息无效。
400INVALID_NOTE_TITLE笔记标题为空或超过 120 字符。
400INVALID_NOTE笔记正文为空或超过 1,000 字符。
400INVALID_NOTE_VERSION更新高亮笔记时未提供原始 updatedAt。
400INVALID_TAG标签名称不符合规则。
400INVALID_COLLECTION收藏夹名称不符合 1–9 字符限制。
400INVALID_BACKUP备份格式、确认标记、管理员账号或表结构不符合要求。
400TOKEN_KEY_MANAGED运行时 Token 密钥策略与备份不兼容。
400MISSING_TOKEN_KEY备份包含 Token 却未提供可恢复密钥。
400IMPORT_FAILED导入事务或外键校验失败。
401INVALID_TOKENToken 缺失、无效、已撤销、所属用户被禁用或权限不足。
403FORBIDDEN完整数据操作需要管理员 Token。
404NOT_FOUND接口或路径参数资源不存在，或不属于当前 Token 用户。
405METHOD_NOT_ALLOWED路径存在，但不支持所用 HTTP 方法。
409NOTE_CONFLICT笔记已更新；重新读取后使用最新 updatedAt 提交。
409DUPLICATE_TAG当前用户已存在同名标签。
409DUPLICATE_COLLECTION当前用户已存在同名收藏夹。
500INTERNAL_ERROR服务器未能完成请求，请稍后重试。
