用户管理

接口访问

API Token

Token 是访问 PaperLeaf API 的密钥。当前账号可在此页查看完整 Token；各类客户端通过 Authorization: Bearer <token> 调用接口。

Edge 扩展

扩展文件位于本版本发行包的 extension/ 文件夹；下载地址为 /extension/manifest.json，下载发行包后保留整个文件夹。

  1. 在 Edge 打开 edge://extensions。
  2. 开启“开发人员模式”，选择“加载解压缩的扩展”。
  3. 选择发行包内的 extension/ 文件夹，并在扩展设置中填入服务地址和此页创建的 Token。
